# LitFlow 快速开始

一个程序，三件事：**管账号**、**翻译论文**、**和 Zotero 打通**。

---

## 一、第一次运行（3 步）

### 1. 双击 `start-litflow.cmd`

会弹一个黑窗口，里面出现 `LitFlow 已启动：http://127.0.0.1:7863/panel/`，
浏览器自动打开面板。

**那个窗口不要关**（关了就等于把程序关了）。它在替你看着网关：万一网关退出，
3 秒后会自动拉起来。

> 想停掉：双击 `stop-litflow.cmd`。

### 2. 填 API 密钥

面板第一次打开会要求密钥。默认是 `config.json` 里的 `api_key` 字段。

想改密码：编辑 `config.json` 的 `api_key`，重启程序。

### 3. 添加账号

面板 → **账号池** → 按提示走授权。加完点「刷新余额」确认积分到了。

---

## 二、装 Zotero 插件（一次就好）

面板 → **PDF 翻译** → 找到「Zotero 集成」卡片：

- 卡片上如果写 **○ 插件未安装** → 点右边的「下载插件」
- 到 Zotero 里：**工具 → 插件 → 右上齿轮 → Install Add-on From File…**
- 选刚下载的 `dualsync@zotero.local.xpi`
- **完全退出 Zotero 再打开**（bootstrap 插件必须重启才生效）

回来刷新面板，卡片应该变成 **● 插件已安装并启用**。

> 如果卡片说「插件已安装但未启用」：到 Zotero → 工具 → 插件 里把它启用，
> 然后重启 Zotero。这一种和「没装」在 Zotero 里看起来一模一样（都是没有菜单）。

### 怎么翻译

在 Zotero 的文献列表里**选中要翻的条目**，然后：

**工具 → Dual Sync：翻译选中条目**

双语 PDF 会生成在条目自己的文件夹里，翻译完自动挂成附件、打上「双语已译」标签。

---

## 三、翻译引擎（pdf2zh）必须单独装

本包**不含** `pdf2zh_next`。原因见包里的 `ABOUT-pdf2zh.txt`（AGPL-3.0 + 体积）。

装法二选一：

**A. 从面板下载**（推荐）—— 面板 → 「环境检测」 → 点「下载 pdf2zh」。
走加速线路，约 592 MB，解压后约 1.2 GB。下完在同一页填路径即可。

**B. pip**

```
pip install pdf2zh-next
```

## 三、翻译引擎（pdf2zh）必须单独装

本包**不含** `pdf2zh_next`。看 `关于-pdf2zh.txt` 了解原因（许可证 + 850 MB）。

```
pip install pdf2zh-next
```

然后把路径写进 `config.json`：

```json
"translate": {
  "pdf2zh_exe": "D:\\zotero-pdf2zh\\server\\zotero-pdf2zh-next-venv\\Scripts\\pdf2zh_next.exe"
}
```

不填会从 PATH 里找 `pdf2zh_next`。

> **也可以从面板改**：设置页 → 「PDF 翻译」 → 填「pdf2zh 可执行文件」。
> 改完「翻译」页会立刻显示引擎是否可用，不用等第一次翻译失败才发现。
> 把它清空 = 回到从 PATH 查找。

---

## 四、选模型（重要，直接影响积分）

面板 → **模型与档位**：

- 每个模型右边有 **关闭** 按钮。关掉的模型不再出现在翻译下拉里 —— 目录里二十几个模型
  大多你永远不会用，关掉能少选错
- 关掉的不会消失：勾上筛选栏的「显示已关闭的」就能找回来重新启用

面板 → **PDF 翻译** → 下拉框：

**在这里选的模型，就是 Zotero 插件实际使用的模型。** 选完立刻保存，不用重启。

> 默认模型不要留 `auto`：它是唯一一个不公布倍率、且明确会浮动的模型。
> 选一个你确认过倍率的。

## 四点五、术语表（可选，但很划算）

翻译同一领域的论文，术语一错就全篇都错，而且**错得一致**。

放一个 CSV 到 `data/glossaries/`：

```csv
source,target,tgt_lng
nanocapsule,纳米胶囊
tannic acid,单宁酸,zh-CN
```

写进 `config.json`：

```json
"translate": {
  "glossaries": ["D:\\workbuddy2api\\data\\glossaries\\agrochemical.csv"]
}
```

> **也可以从面板改**：设置页 → 「PDF 翻译」 → 「用户术语表（CSV 路径）」，
> 多个用逗号分隔。留空 = 不用术语表。改完「翻译」页会显示生效了几份、共多少条词条。

启动时日志会确认：

```
[translate] 术语表 agrochemical.csv：3 条词条
```

**不推荐开 `auto_glossary`**（自动抽取）：它是第二遍全文档 LLM 调用，请求量翻倍，
在按会话限流的池子上会导致连续失败。静态表零额外请求，是同一个目标的安全做法。
详见 `docs/GLOSSARY.md`。

## 五、这个程序会做什么、不会做什么

**会**

- 把所有翻译流量收敛到本机一个端口，账号轮换、限流冷却、积分观测都在这里
- 串行翻译（一次一篇）—— 两个 BabelDOC 进程各约 1.8 GB，并发会拖垮机器
- 翻译历史和任务状态落盘，重启不丢（正在跑的会标为「网关重启时中断」）

**不会**

- 不会编造进度百分比。pdf2zh 在管线下不吐阶段信息，所以只报已用时和 token 总量
- 不会替你改模型选择。你点名哪个就用哪个；`auto` 才走轮换链
- 不会把 pdf2zh 打进包里（AGPL + 体积）

## 六、出问题了看哪里

| 现象 | 先看 |
|---|---|
| 面板报 `Failed to fetch` | 网关没在跑。双击 `start-litflow.cmd` |
| 翻译提交了但没动静 | 面板翻译页看任务状态；`litflow.err` 看子进程输出 |
| Zotero 里没有 Dual Sync 菜单 | 面板卡片看是「未安装」还是「未启用」 |
| 翻译完成但 Zotero 里没附件 | 双语件必须在条目自己的文件夹里；面板翻译页点「复制路径」核对 |
| 想确认网关是否活着 | 浏览器打开 `http://127.0.0.1:7863/health`，返回 JSON 就是活着 |

日志文件：

```
litflow.err                  网关输出（出错先看这个）
litflow-supervisor.log       监管进程的启停记录
data/jobs.json               翻译任务历史
```
